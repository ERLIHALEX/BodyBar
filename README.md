# BODYBAR V3 — статический демонстрационный сайт

Три страницы: `index.html`, `services.html`, `results.html`. Чистые HTML/CSS/JS, без сборщика.

Изменения V3: объединённая навигация «Подобрать уход»; 86 позиций каталога, подробные карточки без 16 изображений прайса; женский/мужской прайс эпиляции (+20%) и расчёт топ-мастера (+20%) для подходящих процедур с зачёркнутой базовой ценой; раздел акций; 8 точек (7 Челябинск, 1 Копейск) со справочными адресами и картой; интерактивный предпросмотр возможной интеграции расписания (не принимает записи); фотогалерея результатов без выдуманных фотопар.

## Данные, которые нужно проверить до официального запуска

- Адреса филиалов собраны из открытых справочников, могут быть устаревшими. Их принадлежность действующей сети и адреса нужно подтвердить у владельца.
- Цены взяты из предоставленного ранее фирменного меню BODYBAR, актуальность требует подтверждения. Наличие топ-мастера для каждого направления и применимость надбавок также требуют проверки.
- Фотографии и логотип предоставлены в исходных материалах; публичное использование требует разрешения владельца прав.
- Встроенная карта использует Яндекс Карты по iframe. Работает только при доступе к интернету, без оплаты API.
- Предпросмотр записи — исключительно интерфейс без настоящих слотов и хранения данных. Кнопка направления записи сейчас ведёт к официальному VK.
- Для готового официального сайта нужны подтверждённые фотопары «до/после» с согласиями, настоящие ссылки записи и согласованная обработка персональных данных.

## Развёртывание

Распакуйте ZIP и откройте `index.html` или загрузите все файлы и папку `assets` в корень репозитория, затем включите GitHub Pages (root).

Meta robots noindex,nofollow сохранён для неофициального демонстрационного проекта.

Мужская эпиляция и топ-мастер: при выборе обоих условий надбавки суммируются от базовой цены (20% + 20% = 40%), не начисляются последовательно. Уточнить у владельца.
